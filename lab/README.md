# Lab Assignments

This folder contains the source code for the lab assignments completed in the Embedded Controller class. These exercises demonstrate how to control various MCU features using the custom-built driver library (`include/`).




## 📋 Lab List


- **LAB_GPIO_Digital_InOut**
- Description: Button input and LED control via direct register access.
  - Result: [[EC 26-2] LAB (GPIO Digital InOut)](https://youtu.be/pcD9_yLGIN8)
- **LAB_GPIO_7segment**
- Description: Displaying numbers on a 7-segment display using GPIO.
  - Result: [[EC 26-2] LAB (GPIO 7segment)](https://youtu.be/reNBhPKHs8o)
- **LAB_EXTI**

  - Description: Event-driven hardware control utilizing External Interrupts (EXTI).
  - Result: [[EC 26-2] LAB (EXTI)](https://youtu.be/A2r5OTkyWjo)

- **LAB_Stepper_Motor**
  - Description: Designing a Finite State Machine (FSM) to accurately control the rotation, speed, and direction of a Stepper Motor.
  - Result: [[EC 26-2] LAB (Stepper Motor)](https://youtu.be/G5TREwSk1WY)
