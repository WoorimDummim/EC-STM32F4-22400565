# EC_HAL API Documentation

​	Welcome to the API documentation for the custom Embedded Controller Hardware Abstraction Layer (EC_HAL). 
This directory contains detailed explanations, register configurations, and usage instructions for each peripheral driver implemented for the STM32F411RE.



## Table of Contents

​	Click on the links below to navigate to the specific documentation for each module:

* [**EXTI (External Interrupt)**](./EXTI_docs.md) : Hardware interrupt configurations, trigger edge settings, and EXTI handlers.
* [**GPIO (General Purpose I/O)**](./GPIO_docs.md) : Pin mode setups, pull-up/pull-down configurations, and digital read/write operations.
*  [**PinNames**](./PinNames_docs.md) : Unified pin mappings, port definitions, and naming conventions for the NUCLEO-F411RE board.
* [**RCC (Reset and Clock Control)**](./RCC_docs.md) : System clock (SYSCLK) configurations, PLL setups, and peripheral clock enablement.
* [**STM32F4v (MCU Definitions)**](./STM32F4v_docs.md) : Core microcontroller register maps, memory addresses, and base macro definitions.
* [**SysTick (System Tick Timer)**](./SysTick_docs.md) : Accurate time delay generation (`delay_ms`, `delay_us`) and system timer initializations.
