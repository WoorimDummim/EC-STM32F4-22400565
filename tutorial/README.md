# Tutorial

This folder contains the source code for the tutorials completed in the Embedded Controller class. These exercises demonstrate how to control various MCU features using the custom-built driver library (`include/`).




## 📋 Tutorial List


- **TU_GPIO_Digital_InOut_Button**
  - Description: Reading button states via digital input and controlling LED output.
- **TU_GPIO_Digital_Out_LED**
  - Description: Basic digital output control to toggle or blink an LED.
- **TU_GPIO_7segment**
  - Description: Displaying numbers on a 7-segment display using GPIO.

- **TU_EXTI**
  - Description:  Implementing external interrupts to handle hardware events asynchronously.
- **TU_SysTick**
  - Description: Utilizing the SysTick timer to generate precise delays and track time.
